Metric dictionary

先判斷方向，才判斷好壞

Accuracy ratio

accuracy_ratio = hqq_top1 / fp32_top1

越接近 1 越好。1 = 完全保留 FP32 accuracy，0.5 = 剩一半。這消除了不同 checkpoint baseline 難度差異的影響，讓跨情境的相對 degradation 可比較。

VRAM reduction

100 × (fp32_vram_gb - hqq_vram_gb) / fp32_vram_gb

越高越好。正值代表 HQQ 比 matched FP32 baseline 使用更少 VRAM。

Params reduction

100 × (fp32_params_m - hqq_params_m) / fp32_params_m

越高越好。它常與 VRAM reduction 同方向。

Time delta

100 × (hqq_time - fp32_time) / fp32_time

越低越好，但只作 exploratory 指標。重跑時間差異很大，先看 quality plot 再引用它。

02 / Grid scan

Heatmaps：bit 與 group 的快速地圖

每張 heatmap 固定 checkpoint kind，將所有 dataset × model context 的同一 (nbits, group size) 取 median。橫軸是 nbits，縱軸是 group size；它回答的是「在這個 checkpoint 類型中，哪個量化區域通常較安全或較省資源」。

Accuracy drop heatmap

讀每格的 median accuracy_ratio。1 = 完全保留 FP32 accuracy，接近 0 = 量化後幾乎無用。這消除了不同 checkpoint 之間 FP32 baseline 差距的干擾（例如 FZ 起點只有 68%、FT 起點 88%），讓相對退化程度可直接比較。

VRAM reduction heatmap

讀每格的 median vram_reduction_pct。高正值表示通常更省 VRAM；必須和 accuracy heatmap 一起看，不能只追求最綠的格子。

03 / Trend changes by context

Interaction plots：同一 bit 不一定有同一效果

interaction_nbits_group_<metric>

每條線代表一個 group size，點是跨其他 context 的 median outcome。若曲線大致平行，group size 只是在整體上下平移；若曲線交叉或斜率差很多，代表 nbits × group_size interaction 值得注意。

interaction_nbits_context_<metric>

每條線代表 cal / ft / fz checkpoint kind。它用來檢查 checkpoint 訓練方式是否改變量化對 bit width 的敏感度。這不是單一 model/dataset 的曲線，而是跨其他 context 的 median。

04 / What explains the variation?

Factor contribution：不是 p-value，而是解釋力

factor_contribution_<metric> 來自 trend regression 的 ablation。每根 bar 表示拿掉某一 term group 後，模型 R² 減少多少（delta R²）。bar 越大，表示該 term 對這份資料網格的預測越重要。

注意：interactions 與主效應會重疊，因此 delta R² 是描述性的 contribution ranking，不是可相加的百分比，也不是顯著性結論。要看係數、reference level、rank、LOOCV MAE/RMSE，請開同層的 factor_effects_*.csv 與 model_fit_*.json。
05 / Statistical summary

Factor importance 排行榜

兩張表回答不同問題：delta R² ablation 來自 levels（categorical）模型，nbits / group_size 各自為獨立的 dummy column、不強制線性關係，能捕捉「低 bit 崩潰、高 bit 趨穩」的非線性 pattern；Spearman ρ 衡量 factor 與 outcome 的單調關聯強度，適合非線性關係，且固定了 confound 情境。

R² 怎麼算： R² = 1 − SSE / SST，其中 SSE = Σ(y_i − ŷ_i)²（殘差平方和，模型沒解釋到的部分），SST = Σ(y_i − ȳ)²（總平方和，資料本身的總變異量）。R² = 0 表示模型不比用平均值猜好；R² = 1 表示完美擬合。

delta R² 怎麼算：先 fit 完整模型得到 R²_full，再把某個 term group（例如 nbits 及其所有 interactions）從設計矩陣中刪除，重 fit 得到 R²_reduced，delta = R²_full − R²_reduced。delta 越大，表示該 term group 在控制了其他 factor 之後，對預測 accuracy 的額外貢獻越多。注意：各 term 的 delta R² 不可相加，因為 term 之間的解釋力有重疊。

與線性 trend model 相比（R²=0.628），levels model 的 R²=0.956 更能捕捉 nbits 對 accuracy 保留比例的真實貢獻——nbits 的 delta 因此從 0.013 升至 0.113。

Spearman within-context 單調關聯性

每個值都控制了 confound 情境：nbits_within_context 固定 (dataset, model, ckpt_kind, group_size)；group_within_context 固定 (dataset, model, ckpt_kind, nbits)。值範圍 −1 至 1。當 Spearman ρ 明顯大於 Pearson r，代表關係非線性但強單調，Spearman 是更可靠的第一手指標。
