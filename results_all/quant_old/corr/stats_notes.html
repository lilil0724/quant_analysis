Quant 統計筆記

以 HQQ 量化分析為例，只用四張圖與一張表解釋 Pearson r、Spearman ρ、R²、delta R² 與 model 選擇。

1. Pearson r vs. Spearman ρ

兩個都衡量兩組數字的關聯性，範圍 −1 到 1，但問的是不同問題。

Pearson r（皮爾森相關係數）

r 問：「兩組數值是否成比例變動？」
公式：
r = Σ[(xi−x̄)(yi−ŷ)] / √[Σ(xi−x̄)² · Σ(yi−ŷ)²]

只捕捉直線關係。若 nbits 對 accuracy 的影響是指數曲線（低 bit 崩潰、高 bit 趨穩），Pearson 會低估關聯強度。

Spearman ρ（斯皮爾曼等級相關係數）

ρ 問：「排名是否永遠同方向變動？」
公式：
ρ = 1 − [6 · Σdi²] / [n(n²−1)]
其中 di = rank(xi) − rank(yi)

只在乎順序，不在乎具體跳多少。不管曲線長什麼形狀（指數、對數、S 形），只要排名方向一致，ρ 就接近 ±1。

何時用哪個？ 若 Pearson r 與 Spearman ρ 差距大 → 關係非線性，用 Spearman 更可靠。若兩者一致 → 關係既線性又單調，用 Pearson 即可。

2. R²（決定係數）

R² 回答：「模型能解釋多少 outcome 的變異？」範圍 0~1。

R² = 1 − SSE / SST
符號計算意義
SSEΣ(yi − ̉i)²殘差平方和：模型沒解釋到的部分
SSTΣ(yi − ŷ)²總平方和：資料本身的總變異量
用這次資料舉例：
所有 864 個 cells 的 accuracy_ratio 總變異固定（SST）。trend model 只用 16 個 parameters 去 fit，SSE 仍有 37% 的變異沒抓到 → R² = 0.628。levels model 用 80 個 parameters，SSE 只留 5% 沒抓到 → R² = 0.956。
R² 越高越好嗎？ 不一定。多加 columns 永遠會提高 R²，即使加的是一個隨機噪聲 column。因此需要「調整後 R²」adjusted R² = 1 − (1−R²)(n−1)/(n−p) 來懲罰多餘的 parameters。trend model adj R²=0.622，levels model adj R²=0.943——加了 64 個 columns 只吃掉了不到 1% 的調整懲罰（因為真正的訊號值那個自由度），這才是好現象。

3. Delta R² Ablation

delta R² 回答：「某個 term group 在控制了其他 factor 之後，對預測額外貢獻多少？」

delta = R²full − R²without_that_term_group 三步驟：
1. 用完整設計矩陣 fit → 得到 R² = 0.948
2. 刪除某個 term group（例如 nbits 的 7 個 dummy columns + 所有 nbits×* interactions）
3. 用縮減矩陣重新 fit → 得到 R² = 0.833
delta = 0.948 − 0.833 = 0.115

4. Trend model vs. Levels model

同樣的 factors，兩種不同的假設，給出完全不同的 R² 與 ranking。

Trend model（線性假設）

nbits = [1, 1.58, 2, 3, 4, 5, 6, 8]
→ 1 個 numeric column

強制 nbits 的效應是直線。1→2 bit 的 accuracy 改善 = 6→8 bit 的改善。

Levels model（不強制線性）

nbits = {1, 1.58, 2, …, 8}
→ 7 個 0/1 dummy columns

每個 bit level 有自己的效應，形狀自由。低 bit 可崩潰 60pp、高 bit 可只差 0.05pp。

指標值
R²0.948
df80 columns
top factornbits（正確）

為什麼 ranking 會翻轉？

trend model 的線性 nbits 無法解釋非線性 pattern，剩餘變異被誤歸因給 group_size。一旦 levels model 用 7 個 dummy columns 正確捕捉每個 bit level 的獨立效應，group_size 的假重要性就消失了——它的真實獨有貢獻只有 0.000003。

Dummy encoding（one-hot）怎麼做？

把一個 categorical 變數展開成多個 0/1 columns。以 8 個 nbits levels 為例，選 n=1.0 當 reference：

原始 nbits1.58234568

40001000

每個 column 的 coefficient 代表「從 reference（1 bit）換到該 level 後，outcome 平均變化多少 pp」。不需要強制線性、也不預設間距相等。
